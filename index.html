How It Works

  1. Read File — Drag & drop your .aep or .ffx file into Retro
  2. Detect Version — Retro automatically reads and shows the file's current AE version
  3. Select Target — Choose which After Effects version you want to convert to
  4. Auto-Backup — Retro creates a safety copy of your original file automatically
  5. Convert — Click Convert — version data updates instantly
  6. Done! — New file saved. Open it in your target version immediately!

Installation Guide

  1. Download the installer button at the top of this page
  2. Locate Setup-Retro-v1.1.1.exe in your Downloads folder
  3. Right-click the file → Select Run as administrator ⚠️ (Required for extension folder access)
  4. Click Next → Agree → Install → Finish
  5. Open After Effects → Go to menu: Window → Extensions → Retro
  6. Drag the panel to your workspace → Pin it → You're ready to go! ✅
💡 Tip: If Retro doesn't appear in the Extensions menu, restart After Effects. If still missing, run the installer again as Administrator.

Frequently Asked Questions

💻 Does it work on Mac?

The installer is Windows-only. Mac support coming in a future update! Meanwhile, you can use the raw extension files directly inside After Effects on Mac.

🔄 Can I convert in both directions?

YES! Convert New → Old (downconvert) AND Old → New (upconvert). Any version to any version!

🛡️ Will my original files get damaged?

NEVER! Retro automatically creates a backup copy named like filename.aep.bak or with a timestamp before touching anything. Your originals are 100% safe.

🔑 Why Run as Administrator?

Adobe installs extensions to a protected system folder. Admin rights are required to write files there. This is standard AE behavior.

🎯 Why do I need to relink footage?

This is NOT a bug — it's normal After Effects behavior when opening projects saved in newer versions. Simply relink ONE file → AE automatically finds ALL others automatically.

📁 What about .aepx or .aep project files?

Retro works with standard binary .aep project files and .ffx presets. XML-based project formats (.aepx) are not needed or supported.

🆘 Can I uninstall it?

Yes! Go to Windows Settings → Apps → Installed Apps → Find "Retro" → Uninstall. Or use the uninstaller from the Start Menu. Everything cleans up completely.

🔒 Is it free forever?

Yes! Retro is free, open source, and will always remain free. No subscriptions, no locked features, no paywalls.

Important Notes

⚠️ About Footage Relinking: When opening a converted project in an older version of After Effects, you may see "Missing Footage" warnings. This is normal After Effects behavior — NOT a bug in Retro! Simply relink ONE footage file → AE finds ALL others automatically.
💡 Best Practice: Always keep your original project files backed up separately. Retro creates automatic backups, but it's good practice to keep archives!
