Installation Steps

  • Download the InstallerClick the button above or get it from GitHub Releases
  • Run as AdministratorRight‑click Setup‑Retro‑v1.1.1.exe → Run as Administrator
  • InstallClick Next → Agree → Install → Finish
  • Open After EffectsGo to Window → Extensions → Retro
  • Done! ✅Pin the panel → Drag & drop files → Start converting!
💡 Troubleshooting If Retro doesn't appear in the Extensions menu → Restart After Effects. If still missing → Run the installer again as Administrator. Admin rights are required because extensions install to a protected system folder.

How It Works

  • 📄 Read FileDrag & drop your .aep or .ffx file into Retro
  • 🔍 Detect VersionRetro automatically reads & displays the file's current AE version
  • 🎯 Select TargetChoose which AE version you want to convert to

⚠️ About Missing Footage When opening a converted project in an older version, you may see "Missing Footage" warnings. This is NORMAL After Effects behavior — NOT a bug in Retro! Simply relink ONE file → AE finds ALL others automatically.

Frequently Asked Questions

🔄 Can I convert in both directions?

YES! Convert New → Old (downconvert) AND Old → New (upconvert). Any version to any version! No limits.

🛡️ Will my original files get damaged?

NEVER! Retro automatically creates a backup copy named like filename.aep.bak or with a timestamp before touching anything. Your originals are 100% safe.

💻 Is there a Mac version?

The installer is Windows‑only. Mac support coming in a future update! Meanwhile, you can use the raw extension files directly inside After Effects on Mac.

📁 What about .aepx files?

Retro works with standard binary .aep project files and .ffx presets. XML‑based project formats (.aepx) are not needed or supported.

🆘 Can I uninstall it?

Yes! Go to Windows Settings → Apps → Installed Apps → Find "Retro" → Uninstall. Or use the uninstaller from the Start Menu. Everything cleans up completely.

🔒 Is it really free forever?

YES! Free, open source, no subscriptions, no locked features, no paywalls. The code is on GitHub — verify it yourself!
