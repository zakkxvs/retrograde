Installation Guide

  1. Download the installer button above
  2. Right-click Setup-Retro-v1.1.1.exe → Run as Administrator
  3. Click Next → Install → Finish
  4. Open After Effects → Window → Extensions → Retro
  5. Pin the panel → Start converting! ✅
💡 Tip: If Retro doesn't appear, restart After Effects. Admin rights are required because Adobe installs extensions to a protected system folder.

Frequently Asked Questions

🔄 Can I convert in both directions?

YES! Convert New → Old (downconvert) AND Old → New (upconvert). Any version to any version!

🛡️ Will my original files get overwritten?

NEVER! Retro automatically creates a backup copy before conversion. Your originals are 100% safe.

💻 Is there a Mac version?

The installer is Windows-only. Mac users can use the raw extension files directly from GitHub.

🎯 Why do I see "Missing Footage" after converting?

This is normal After Effects behavior — NOT a bug. Relink ONE file → AE finds ALL others automatically.

🆘 Is it really free forever?

YES! Free, open source, no subscriptions, no locked features, no paywalls.
