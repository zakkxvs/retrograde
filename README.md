# Retro — After Effects Project Converter
Convert After Effects projects (.aep) and presets (.ffx) between ANY versions. Save in new, open in old — or vice versa.

## ✨ Features
- 🔄 Convert .aep project files
- 🎨 Convert .ffx animation presets
- 📦 Batch convert multiple files
- 💾 Auto backup originals
- ⚙️ One-click installer

## 📥 Download
Latest version: **Retro v1.1.1** — See Releases page.

## 💻 Usage
1. Download & Install → Run as administrator
2. Open After Effects → `Window → Extensions → Retro`
3. Select file → Choose target version → Click Convert

## ✅ Compatibility
- After Effects: CS6 → 2026
- Windows 10 / 11
